# MAH CORE Operations

**Integrated Technical Operations Management**  
Created by **Mohamed Ali Hbibi**.

MAH CORE is the evolving name and brand of the IOTEK technical-operations application. The application currently includes mission management, time tracking, work evidence and reports.

## Project principles
- Preserve existing features and stored data during incremental improvements.
- Keep the existing Industrial Operator visual identity.
- Make the Accueil dashboard the first screen and organize technical operations into clear modules.
- Protect data with server-side access controls and validate changes before deployment.

## Application
The app is delivered as a web application/PWA. The manifest and HTML metadata use the MAH CORE brand.

> The repository name remains `IOTEK` for now; changing the repository URL is a separate operation and is not required for the in-app rebrand.
